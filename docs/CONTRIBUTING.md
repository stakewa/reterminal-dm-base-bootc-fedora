# Contributing

Contributions are welcome. But may take a while to get merged

## Before you open a pull request

- Keep the documentation aligned with the scripts and container files in this repository.
- Ensure that the documentation is up-to-date with the latest changes in the codebase.
- Test the changes in a development environment before submitting a pull request.

If you add new procedures or scripts, update the relevant document in `docs/` at the same time.
